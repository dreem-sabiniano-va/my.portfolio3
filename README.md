# Dreem Sabiniano — operations VA portfolio

A responsive, motion-led portfolio built with HTML, CSS, and vanilla JavaScript. No build step or framework is required.

## Preview

Open `index.html` in a browser. For best behavior with all browsers, serve this folder through any static host or local web server.

## Customize

- `content.js` contains the service descriptions, tools, contact links, and project stories.
- `styles.css` contains the ivory, charcoal, and rose design system, responsive layouts, and motion.
- `script.js` renders the cards, runs the VA-fit questionnaire, and handles the project details dialog and carousel.
- Replace `dreem-portrait.png` and the `project-*.png` images to update visuals.

Visit the page with `#edit` to replace images locally in that browser. Changes in photo edit mode are stored in local storage and are not uploaded; replace the image files in this folder to publish them for all visitors.

## Project links

The two Notion work samples link to their public pages. Check their sharing settings and preview them in a private browser window before publishing. The PDF samples are included in this folder; the document management card links to the supplied Google Drive folder.

## Publish

Upload the contents of this folder to a static host such as GitHub Pages or Netlify. Confirm all project links and contact methods after deployment.
